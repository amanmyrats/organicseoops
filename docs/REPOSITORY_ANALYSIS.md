# Read-Only Repository Observations

P16-01/D440/D441/D442/D443 local source is written and **untested** under D437. Inventory, optional advisory and selected-source observation intake are disabled by default. This runbook is a deployment-preparation artifact; no container, service, image build, repository collection or provider operation has been performed. The marked independent Security review, actual rootless containment/cleanup acceptance, legal/provider readiness and manual accessibility remain open.

The explicit `root_dependency_inventory` operation reads only root `package.json`, `pyproject.toml` and `requirements.txt` at an authorized full GitHub commit. It parses declared dependency constraints in a disposable offline container; it does not resolve/install dependencies, identify installed versions/CVEs, recursively inspect code, execute repository scripts or invoke a coding agent. Unsupported/private URL/secret-like declarations are counted and excluded. Overflow and malformed inputs fail rather than implying complete coverage. The optional advisory mode below queries OSV for supported exact declared pins; broader resolved/transitive/code scanning and P16-02 patches/checks/PRs remain unfinished.

## Optional OSV advisory lookup

No provider credential/account setup is required by the code; no lookup has been performed.

Only full exact npm semantic versions and the implemented strict subset of exact PyPI `==` versions are queried. Ranges, wildcards, unpinned/dynamic/unsupported declarations are counted as excluded; no resolver, install or assumed installed version is used. Duplicate ecosystem/name/version queries are combined with original dependency indices (PyPI separators normalize to hyphens). Sorted unique pins beyond50 are counted as skipped. With no eligible pin the result is `no_exact_pins`, vulnerability assessment unavailable, and no OSV attempt/unit is consumed. This is not zero vulnerabilities.

One fixed-host15-second `POST /v1/querybatch` sends at most32KiB and reads at most512KiB strict JSON, with public-address DNS/TLS controls and no redirects/retry/pagination. Reserve14 maximum internal units instead of inventory's13, counting <=13 actual GitHub reads and<=1 actual OSV batch; units are distinct from provider pricing/quota. A durable OSV attempt step precedes the wire and remains chargeable on unknown/failed outcome. Cleanup, cancellation, usage reconciliation and original-source private API/export withholding remain unchanged. A provider error/malformed response fails the combined request without presenting an empty clean result or automatically retrying it.

Result ordering maps each package to the official batch response. Retain at most10 IDs/package and100 overall, modified dates, returned-page counts, complete flags, query time and response SHA256; do not retain pagination tokens, descriptions or raw provider bytes. Provider pagination or retention limits mark that row incomplete; unsupported declarations and skipped pins mark coverage partial. `complete_for_queried_pins` describes that narrow query set only. Advisory IDs may overlap and are not a unique CVE count. No severity/fix/reachability/exploitability/installed/transitive/whole-repository-security assertion or automatic remediation approval follows. Combined retained job output is <=64KiB. The native screen labels the selected mode, request counts, consent and gaps, and uses mode-specific uncertainty keys.
